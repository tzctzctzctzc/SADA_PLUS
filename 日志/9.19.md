### P048 正信号与突破口审计
- 事项：基于 P048 的正信号和 2025–2026 年相关工作，审计可形成主线的方法突破口。
- 结论：冻结模型已将 123/128 个正样本召回到 Top-10，说明主要瓶颈是正确语义邻域内的角色错绑，而不是粗粒度召回。文本角色换位相对冻结模型的 binding 配对翻转为 24 改善、3 退化（exact McNemar p=4.9e-5）；相对图像换位为 6 改善、1 退化（p=0.125），因此“文本换位优于图像换位”目前只由 binding margin、mAP@10 和 R@10 的连续/排序指标支持，不能按离散准确率宣称确定优势。
- 突破口：优先证伪“冻结全局语义检索器 + 候选感知的共享目标反事实角色残差/验证器”。它只在冻结检索器的 Top-K 内学习原查询相对单角色换位查询的候选分数差，从结构上避免 P048 的全局几何坍塌；普通多负样本和通用几何正则仅作为必要对照。
- 新颖性边界：两阶段重排、流形保持微调、显式参考绑定分别已有近作；潜在新颖性只能落在多参考检索中的“角色索引共享目标干预监督 + 候选级相对验证 + 冻结几何部署”组合。当前 126/128 个验证样本属于 color，尚不能外推到身份或一般属性角色。
- 涉及：runs/P048_visible_role_contrast/pilot_summary.json、diagnostics.json；2025–2026 年 CIR、绑定与流形保持相关文献。

### 反事实角色验证器方案细化
- 事项：细化主突破口的模型结构、监督目标和新颖性边界。
- 结论：采用冻结基础检索器与候选感知角色验证器的两阶段结构。基础检索器维持全图库语义几何；验证器对同一候选分别计算原查询和单角色文本换位查询的兼容度，以候选级反事实差分作为残差分数，并用正目标与硬负目标之间的差分排序、改写一致性和负对照约束训练。
- 新颖性：核心不是一般重排或几何正则，而是将共享目标的角色干预转化为候选级 difference-in-differences，并从结构上隔离全局召回与局部关系绑定。首个 pilot 先使用可表达的 cross-encoder verifier 验证机制，暂不为效率牺牲表达能力。
- 涉及：P049 待确认方案；runs/P048_visible_role_contrast/pilot_summary.json、diagnostics.json。

### P049 候选级反事实角色验证器
- 事项：在物理 GPU1 上实现并执行“冻结检索器 + 候选感知 8B verifier”的三臂大 pilot；三臂为普通 verifier、单正目标反事实、difference-in-differences（DoD）反事实。
- 数据：144/128/64 个 train/validation/confirmation bundle，共 336 组、1,344 个实验内全局不交叉商品；训练与 heldout 商品零重合，validation/confirmation 与 P048 完全一致。确认门槛继承 P048 的 identity 64/64、cross-role negative 60/64。
- 实现审计：最终版本静态和运行时审计均为 faithful。36/36 个语言 LoRA 层、视觉 merger、标量 head、原始/交换的正负候选及改写分支均有梯度；冻结 base 不在优化器中。审计在训练前发现并修复环境路径错误、base 长度不一致和 system prompt 偏差；修复后精确复现 P048 frozen mAP@10 0.79838、R@10 0.96094。
- 结果：普通 verifier 的 mAP@10/改写 mAP 为 0.85677/0.80614。单正目标反事实为 0.87943/0.68533，显示明显语言表面形式捷径。DoD 为 0.84979/0.83953，binding accuracy 0.94531、DoD pair accuracy 0.90625、hard-negative 违例率 0.07031。
- 统计：DoD 相对 frozen 的 mAP 增益 +0.05141（95% CI [0.01424, 0.09094]），改写 mAP 增益 +0.10760（[0.06437, 0.15396]），相对普通 verifier 的 DoD margin 增益 +0.22271（[0.17048, 0.27544]），hard-negative 违例变化 -0.0625（[-0.11719, -0.015625]）。但主 mAP 相对普通 verifier 为 -0.00698（[-0.03639, 0.01942]），唯一失败门槛是未超过强 verifier 控制。
- 诊断与结论：DoD 相对普通 verifier 为 7 条改善、110 条不变、11 条变差；DoD 内 raw/delta 主 mAP 为 0.85359/0.84979，而改写 mAP 为 0.82930/0.83953，说明统一使用角色差分造成效用与稳健性的取舍。当前 126/128 个验证样本的活动角色为 color，不能外推到一般角色。P049 停止，不进入全量；下一轮只能以独立校准的选择性角色残差或受约束多目标训练为证伪点，并补足非 color 角色。
- 迁移思路：借鉴推荐/检索中的召回器—验证器级联、因果表示中的干预效应不变性、多目标优化中的效用—稳健性约束，以及 teacher-to-retriever 蒸馏；这些通用工具本身不作为新颖性，潜在贡献仍须落在多参考检索的角色索引候选效应及其可靠使用条件。
- 涉及：configs/P049_counterfactual_role_verifier.json；scripts/prepare_P049.py、extract_P049_images.py、audit_P049_implementation.py、analyze_P049.py、run_P049.sh；src/run_P049.py；runs/P049_counterfactual_role_verifier；research_state.json。

### 当前方向 SOTA 可行性全面审计
- 审计范围：以当前 active topic“多参考 composed image retrieval / PinPoint 多图查询中的角色绑定与候选验证”为准；早期 SADA 时间动作检测路线不作为本方向的 SOTA 证据。
- 结论：当前 P049 不能称 SOTA，也没有与官方全图库结果可直接比较的数字。P049 是 144/128/64 bundle 的局部 Top-10 重排 pilot；DoD mAP@10 为 0.84979，低于普通 verifier 的 0.85677，但改写 mAP 为 0.83953，显著高于 frozen 的 0.73192。方向仍有高开发潜力，当前 conference readiness 为 low。
- 优势：问题重要且仍开放；PinPoint 报告多图查询约占 13.4%，不同方法性能低 40–70%，并暴露 hard-negative 与 paraphrase 脆弱性。P049 的共享目标 DoD 在 frozen baseline 之上显著提升改写稳定性、角色 margin 和 hard-negative 控制；数据商品隔离、视觉门槛、静态/运行时审计和失败即停规则较强。
- 劣势：尚未完成 PinPoint 官方全图库 mAP/Recall/NegRecall；普通 verifier 已是强控制，DoD 尚未超过它；验证样本几乎全是 color（126/128），非 color、identity、partial/noisy-reference 未覆盖；只有 Qwen3-VL-Embedding-8B、单 seed、单数据来源；没有近期强方法、跨模型、跨数据集和推理成本对比；Top-10 rerank 不能解决第一阶段召回缺失。
- 理论审计：difference-in-differences 只有在角色交换是语义有效干预、共享 target 难度可抵消、候选偏置在两次查询中近似稳定时才具有清晰解释。P043/P045 的视觉门和跨裁判一致性说明这些假设尚未普遍成立，因此当前可声称“相对角色效应信号”，不能声称因果推理或普适角色绑定。
- 新颖性审计：通用 verifier、Top-K rerank、MLLM evidence verification、counterfactual/invariance CIR 和 adaptive reranking 均已有 2025–2026 近邻。剩余可 defend 的增量只能是“多参考检索中特定角色的候选级效应估计 + 独立校准的选择性使用条件 + 全图库/多角色验证”，不能把普通 verifier 或 delta rerank 单独包装为创新。
- 决策：不进入全量。下一步仅允许 P050 selective-effect pilot：以 ordinary verifier 作为效用锚点，独立 calibration split 学习何时使用 role-effect residual，补足非 color 角色；门槛必须包括相对 ordinary 的 paired mAP 提升、改写非劣、hard-negative 改善、至少两个模型或数据域复现。
- 涉及文献：PinPoint arXiv:2603.04598；CoLLM CVPR 2025/arXiv:2503.19910；MCoT-MVS arXiv:2603.17360；UniCVR arXiv:2604.20318；EviRank arXiv:2608.20886；INTENT AAAI 2026；Recommendation Retrievers Need Verifiers arXiv:2609.12270。

### SOTA 目标调整
- 讨论结论：不把“全体 benchmark 总榜第一”作为唯一目标；若方法在官方定义的 multi-image 子集上达到部分 SOTA，同时整体/单图查询非劣，并在 hard-negative、paraphrase 和 role-binding 指标上形成同一机制链，也具有完整论文价值。
- 约束：multi-image 子集必须按 PinPoint 官方类别预先固定，不能按方法收益挑样本；必须同时报告全体、multi-image、single-image、显式负例和改写结果，并与近期强方法同协议比较。
- 故事线：多参考查询更容易发生角色错绑；绝对关系判断不稳定但候选级角色干预效应更稳定；普通 verifier 提供效用，选择性 role-effect residual 修复多图 hard-negative/改写脆弱性；最终形成“部分 SOTA + 全体非退化 + 机制解释”的贡献，而非通用 verifier 包装。
- 下一步：P050 的主门槛改为 multi-image mAP@10 或 NegRecall@10 的 paired 提升、整体/单图非劣、paraphrase 非劣和非 color 角色覆盖；若只提升代理 binding 指标而不提升官方多图任务指标，仍停止扩展。
